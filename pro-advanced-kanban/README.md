# Enterprise Kanban

This showcase projects one canonical RevoGrid source into an Enterprise Kanban board. It demonstrates workflow columns, team swimlanes, WIP limits, card rules, custom card content, column and lane collapse, and drag-and-drop card movement.

Equivalent entry points are provided for TypeScript, React, Vue, and Angular. Shared data and configuration live in `src/kanban.shared.ts`.

Run a framework variant from the `revogrid-demos` root:

```bash
pnpm dev:kanban
pnpm dev:kanban:react
pnpm dev:kanban:vue
pnpm dev:kanban:angular
```
