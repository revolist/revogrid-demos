# AI Agent

This demo shows natural-language grid actions and answers alongside an orders grid. Suggested requests work with bundled scripted responses. A compatible same-origin AI backend at `/api/ai-view/interpret` enables free-form requests.

From this directory, run `pnpm dev:vue`, `pnpm dev:react`, `pnpm dev:angular`, or `pnpm dev:ts`. The demo requires a RevoGrid Pro build that exports the AI Assistant APIs. Inside the Pro workspace, Vite uses its built Pro package when available.
