# Construction Gantt: Simple Portfolio

A focused wrapper around the canonical `simple-construction` Gantt use case. It
keeps one mounted Gantt source while moving between the company portfolio,
project focus, and an inclusive Look-Ahead date range.

```bash
pnpm dev
pnpm build:frameworks
```

The TypeScript, React, Vue, and Angular implementations remain owned by
`pro-advanced-gantt/src/use-cases/simple-construction/`; this workspace provides
the standalone gallery entry and framework bootstraps.
