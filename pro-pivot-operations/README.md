# Support operations Pivot

Focused Vue demo of support-ticket volume, average resolution time, SLA breaches, and source-record investigation. The synthetic 480-ticket fixture is deterministic and contains no customer information.

Select a team or priority to filter the Pivot and the ticket table together. The table lists the exact records in the selected scope. Focus a Pivot value cell, then choose **Inspect focused value cell** to show the matching records from that same filtered source. Public Pivot row and column metadata define the focused cell's scope. The detail panel identifies whether it shows the selected scope or a Pivot cell.

Run `pnpm test`, `pnpm build`, or `pnpm dev` from this package. Gallery registration and the other three framework variants are owned by the integration step of the Pivot roadmap.
